## 게임 컨셉

### High Concept

**기존**
- 두 개의 버튼을 조합하여 행동을 예약하고, 갱신되는 커맨드에 따라 캐릭터를 이동시켜 장애물을 돌파하는 2D 무한 러너 게임입니다.

**변경**
- 분리수거장에서 굴러 나온 박스가 자신을 잡으러 오는 사람들을 피해 도망치는 2D 무한 러너 게임입니다.
- 플레이어는 박스를 직접 조작하지 않고, O/X 2슬롯 커맨드 큐로 박스의 행동을 지시합니다.
- **1단계(Side-View 횡스크롤 도주) → 2단계(Top-View 골목 미로) → 1단계 …** 형태로 무한 반복됩니다.

### 핵심 메카닉

**기존**
- 화면의 두 개 버튼(O, X)을 누르면 행동칸 두 개에 입력이 순차적으로 저장되어 캐릭터의 행동이 결정됩니다.
- 행동이 발동된 후에도 기존 커맨드가 비워지지 않습니다. 새 버튼을 누르면 가장 오래된(왼쪽) 버튼이 밀려나고 새로운 조합이 즉시 완성됩니다.
- 조작을 멈추고 제자리에 일정 시간 머무르면 바닥이 무너져 게임이 종료됩니다.
- 장애물을 커맨드 조합으로 뛰어넘어 점수를 획득하며, 장애물과 충돌 시 즉시 게임이 종료됩니다.
- 게임 진행 중 특정 아이템을 획득하면 일정 시간 동안 시점이 Side-View(횡스크롤)에서 Top-View(종스크롤)로 전환되며, 게임의 진행 방향(아래에서 위로)과 커맨드 조합에 따른 이동 방식이 완전히 변경됩니다.
- 커맨드 조합별 이동 (Side-View / Top-View)
    - Side-View
        - O + O: 오른쪽으로 2칸 이동
        - O + X: 오른쪽으로 1칸 이동
        - X + O: 오른쪽으로 1칸 이동
        - X + X: 오른쪽으로 3칸 이동
    - Top-View
        - O + O: 오른쪽으로 1칸 이동
        - O + X: 위로 1칸 이동
        - X + O: 위로 1칸 이동
        - X + X: 왼쪽으로 1칸 이동

**변경**
- 2슬롯 밀어내기 커맨드 시스템과 커맨드 조합별 이동 칸 수는 기존과 동일합니다.
- ~~제자리 체크 → 바닥 무너짐~~ → **관리사무소 아저씨**가 화면 왼쪽에서 점진적으로 접근(시각화된 타임아웃). 박스가 장애물에 걸려 느려지면 거리가 줄어들고, 거리가 0이 되면 게임 오버.
- ~~장애물 충돌 = 즉시 게임 오버~~ → 장애물 종류에 따라 효과가 분기 (1칸 / 2칸 / 멈춤형, 아래 "장애물" 참고).
- ~~아이템 획득으로 Top-View 진입, 일정 시간 후 Side-View 자동 복귀~~ → **Side-View 오른쪽 끝 도달 → 환경미화원 등장 → Top-View 미로 도주**. 미로를 빠져나가면 다시 Side-View로 돌아오는 무한 반복 구조.

### 장애물 (신규)

**1칸짜리** — `O+O` 또는 `X+X` 강제
- 종량제 쓰레기봉투
- 음식물 쓰레기통
- 고양이

**2칸짜리** — `X+X` 강제
- 빗물 웅덩이 (닿으면 감속, 소프트 페널티)
- 하수구 맨홀
- 버려진 자전거

**멈춤형 (별도 메커닉)**
- 자동차 (횡단보도) — 점프 불가, 박스가 멈춰서 대기 → 추격자와의 거리가 줄어드는 텐션 메커닉

### 추격자 / 행인 (신규)

- **관리사무소 아저씨** — Side-View 단계에서 화면 왼쪽에서 박스를 추격
- **환경미화원** — Side-View 오른쪽 끝에 등장해 Top-View 단계로 전환시키고 미로에서 박스를 추격
- **행인** — 배경이 아닌 별도 게임 오브젝트. 박스보다 한 단 위 인도 안쪽에서 양쪽으로 등장하며, 추격자와 시각적으로 구분 (유니폼/도구 없음).
